# overview_add_na_output

Function used in \`overview_na\` to generate a new data frame with
na_count and percentage share of NAs for each row

## Usage

``` r
overview_add_na_output(dat_result = NULL, dat = NULL)
```

## Arguments

- dat_result:

  Data.frame from \`overview_na\`

- dat:

  Data frame

## Value

The function returns a data set that has the information on the row-wise
NA share
