# overview_plot_absolute

Function used in \`overview_na\` to plot the absolute share of NA values

## Usage

``` r
overview_plot_absolute(
  dat_result = NULL,
  theme_plot = NULL,
  yaxis = NULL,
  xaxis = NULL
)
```

## Arguments

- dat_result:

  Data frame

- theme_plot:

  Theme for the plot (pre-defined)

- yaxis:

  Name for yaxis

- xaxis:

  Name for xaxix

## Value

The function returns a ggplot
