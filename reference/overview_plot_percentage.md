# overview_plot_percentage

Function used in \`overview_na\` to plot the percentage share of NA
values

## Usage

``` r
overview_plot_percentage(
  dat_result = NULL,
  theme_plot = NULL,
  yaxis = NULL,
  xaxis = NULL
)
```

## Arguments

- dat_result:

  Data frame

- theme_plot:

  Theme for the plot (pre-defined)

- yaxis:

  Name for yaxis

- xaxis:

  Name for xaxix

## Value

The function returns a ggplot
